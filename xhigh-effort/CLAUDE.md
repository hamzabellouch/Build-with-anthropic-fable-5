This is a blank Next.js project.
The project is effectively a directory to demonstrate different themes and designs for landing pages.
All data in this project is fake.
You can assume brand names, mission, vision, and themes.
When asked to make a landing page, you don't change the current one, rather, you create a new one and make the path for it with the following formula: `/<number of current landing pages + 1>` -> if we already have 4 landing pages, and you got asked to do a landing page, the url for that landing page must be `/5`
